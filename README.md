# Puberty and Emotional Reactivity in Female Adolescents With and Without ADHD

This repository contains the data processing and analysis code for a study investigating relationships between puberty and emotional reactivity in female adolescents, and whether these relationships are moderated by ADHD status.

## Repository Contents

All data processing and analysis code can be found in the [Data Processing and Analysis](https://github.com/emily-j-f/PERS/tree/main/Data%20Processing%20and%20Analysis) folder.

The files are presented in the order in which they were run for the study:

1. Raw data frame preparation
2. Data cleaning
3. Descriptives
4. Multiple imputation
5. Post-imputation data processing
6. Prior predictive checks
7. Hypothesis testing models
8. Supplementary models
9. Sensitivity models
10. Exploratory moderated mediation model

A [Data Dictionary](https://github.com/emily-j-f/PERS/tree/main/Data%20Dictionary) is available to assist with interpreting the code and understanding the variables used in the study.

PDF outputs from the R analyses, including multiple imputation diagnostics, can be found in the [R PDF Outputs](https://github.com/emily-j-f/PERS/tree/main/R%20PDF%20Outputs) folder. And the data collection tools (surveys) can be found in the [Survey PDFs](https://github.com/emily-j-f/PERS/tree/main/Survey%20PDFs%) folder.
